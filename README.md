# Third + Grove Brand Guidelines

Source for brand.thirdandgrove.com. Rendered from Bradley's Claude artifact on November 10, 2026.

## What's here

| Path | What it is |
|---|---|
| `index.html` | The guide. Same page as the artifact, with asset-store references (`/_blob/<id>`) pointed at local files. Fonts, photos, and logos are still inlined. |
| `source/artifact-original.html` | Untouched export of the artifact, for reference. Do not publish. |
| `assets/logos/` | 4 lockups × black/white, SVG and PNG (PNG widths: 2400, 1600, 1200, 512). |
| `assets/icons/` | 5 service icons as SVG (black/white) and 6 animations as MP4 (black/white, including the combined Services loop). |
| `assets/photography/` | 100 WebP images in 5 family folders, plus the family video posters. |
| `assets/video/` | Hero, family background, and section videos. |
| `assets/images/` | Other images the page uses. |
| `assets/palette/` | Palette as CSS variables, JSON, and Adobe Swatch Exchange (.ase). |
| `assets/fonts/` | FK Grotesk, 12 styles, .woff2. |
| `downloads/` | Prebuilt zips behind every download button, plus a full brand kit. |
| `manifest.json` | Every file with its size, SHA-256, and role. |
